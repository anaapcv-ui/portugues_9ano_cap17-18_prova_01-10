Uma corrente só segura peso quando cada elo está fechado. Aqui, cada elo é uma parte do estudo — e o assunto da prova é justamente isso: as palavras que ligam ideias sem repetir (os pronomes relativos) e as orações que se prendem a um nome para caracterizá-lo (as adjetivas).

🔗 Os quatro elos — siga nesta ordem

📖

1. Leitura Guiada

Onze elos de leitura, do raciocínio dedutivo até as orações adjetivas. Em cada elo você escreve três respostas com as suas palavras e confere com a resposta modelo. Termina com as 10 pegadinhas da prova.

 Elo 1 🎯

2. Quiz

18 questões objetivas para testar logo o que acabou de ler, enquanto o assunto está fresco. No fim sai o código MED, que abre o gabarito comentado.

 Elo 2 🗺️

3. Resumo

O resumo de bolso: quadros comparativos, cartas dos pronomes para virar, post-its com as dicas que mais caem e o glossário da prova. Use para fechar exatamente as lacunas que o Quiz revelou.

 Elo 3 📝

4. Simulado

28 questões no estilo vestibular: somatório, números romanos e objetivas. No fim sai o código SIM, que abre o gabarito comentado questão por questão.

 Elo 4

📋 Como usar este material

  1. Comece pela Leitura Guiada. Não pule a parte de escrever: é escrever que faz a matéria grudar. Se você copiar o texto do elo, o material pede para reescrever com as suas palavras.
  2. Vá para o Quiz logo depois, enquanto o assunto está fresco. Ele mostra onde a corrente está frouxa.
  3. Use o Resumo para fechar exatamente essas lacunas — e vire as cartas dos pronomes tentando responder de cabeça antes.
  4. Só então encare o Simulado, valendo. Ele é o mais parecido com a prova de verdade.
  5. Tudo fica salvo sozinho no navegador. Dá para fechar e voltar depois que nada se perde. Se for estudar em outro aparelho, use o botão 📥 Exportar num e 📤 Importar no outro.
📌 Dica para o jovem aprendiz Antes da prova, releia só três coisas: as 10 pegadinhas no fim da Leitura Guiada, o quadro explicativa × restritiva do Resumo e a tabela de regência (qual preposição cada verbo pede). É de onde vem a maior parte dos erros.
